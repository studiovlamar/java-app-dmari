# SkillBrain Java App

## Lectia 2

Aplicatia:
- este construita ca artefact Maven (.jar)
- este publicata in GitHub Packages
- este rulata intr-o imagine Docker (GHCR)

### Tag-uri folosite
- latest – ultima versiune
- sha-<commit> – versiune specifica pentru fiecare commit

### Diferenta
- artefact = fisierul .jar
- imagine = aplicatia + mediul de rulare (Docker)
